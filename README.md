## Setup Locally

```bash
# Install dependencies
pip install -r requirements.txt

# Copy your saved models from notebook
cp saved_models/*.h5 models/
cp results/frontend_data.json results/

# Run locally
uvicorn app.main:app --reload --port 8000
```

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | API info |
| GET | `/health` | Health check |
| GET | `/sections` | List all sections + loaded status |
| GET | `/classes` | All 43 class names |
| POST | `/predict/{section_key}` | Predict using specific section model |
| POST | `/predict/all` | Run through all 7 models + majority vote |
| GET | `/results/summary` | Grand summary from notebook |

## Section Keys
- `section1`  — Optimizer & LR
- `section2`  — Optimizer x LR x Batch Size
- `section3a` — DNN vs CNN (No Augmentation)
- `section3b` — DNN vs CNN (With Augmentation)
- `section4a` — Deep DNN vs CNN (No Augmentation)
- `section4b` — Deep DNN vs CNN (With Augmentation)
- `section5`  — Transfer Learning (ResNet50/MobileNetV2/VGG16)

## Deploy on Render

1. Push this folder to GitHub
2. Go to [render.com](https://render.com)
3. New → Web Service → Connect GitHub repo
4. Build command: `pip install -r requirements.txt`
5. Start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
6. Add your `.h5` model files via Render's persistent disk or use Git LFS

## Example Usage

```python
import requests

# Single section prediction
with open('sign.jpg', 'rb') as f:
    response = requests.post(
        'http://localhost:8000/predict/section5',
        files={'file': f}
    )
print(response.json())

# All models prediction
with open('sign.jpg', 'rb') as f:
    response = requests.post(
        'http://localhost:8000/predict/all',
        files={'file': f}
    )
print(response.json())
```
